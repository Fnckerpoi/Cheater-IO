## 🌟 本分支核心扩展与功能说明

本分支专注于 **ESP32-C3 + BMP280 硬件遥测** 与 **RayNeo 智能眼镜实时字幕（AI_SUBTITLE）实时推送**，实现了完整的闭环物理联动。

### 1. 核心特性
- **物理接近自动感知（Proximity Sensing）**：
  - 基于低功耗蓝牙（BLE）广播信号强度（RSSI）进行现场标定与进入/离开判定（默认约 1 米）。
  - 采用 3 包连续有效读数入场防抖与 6 dB 迟滞退出保护，防止门限边缘频繁颠簸。
- **端到端硬件加密通信（AES-128-GCM）**：
  - ESP32-C3 端采集 BMP280 环境温湿度/气压，每 500ms 进行一次原生 AES-128-GCM 加密，并以 100ms 间隔广播。
  - Android 扩展端实时接收、无损解密并核验 96 位认证标签（Tag）与单调递增防重放计数器（Replay Counter）。
  - 支持凭据轮换与账本持久化，损坏状态严格拒绝启动。
- **智能眼镜事实字幕无缝轮转（Auto-Reentry）**：
  - **靠近自动显示**：人走近传感器，眼镜端自动拉起字幕通道，显示温度与气压实时读数。
  - **离开自动回首页**：走远后软件触发安全退出，眼镜自动关闭字幕，平滑退回系统主菜单。
  - **再靠近自动重入**：离开超过冷却期（8 秒）后再次靠近，系统自动分配全新会话 ID（SID）并重新开启显示，**全程无需掏出或操作手机**。
- **高安全性与系统互斥保护**：
  - **单业务独占隔离**：严格隔离显示会话所有权（Owner/Epoch），不抢占、不污染原生导航、云端字幕或音乐等其他眼镜业务通道。
  - **纯本地事实流**：全链路 0 AI 模型调用、0 麦克风录音、0 云端转写，保护隐私且极度省电。

## 🚀 快速上手 (Quick Start)

### 1. 固件准备 (ESP32-C3)
源码位于 esp32-scada/ 目录下，使用 ESP-IDF 5.5 编译与烧录：
`powershell
cd esp32-scada
idf.py set-target esp32c3
idf.py build
idf.py -p COM3 flash monitor
`
在控制台输入一次性密钥配置命令（密钥需与手机端一致）：
`	ext
scada> provision <32位十六进制AES密钥> <16位十六进制设备前缀>
`

### 2. 手机端运行与配置
1. 打开手机端 TurboIO TMIG1刷写（或基于此分支构建的测试包）。
2. 进入 **SCADA sensor（本机实验）** 页面。
3. 填入与 ESP32 相同的密钥与前缀，点击 **Save encrypted lab provisioning**。
4. 点击 **Start SCADA BLE scan** 开始扫描。
5. 手机与眼镜保持连接，靠近传感器至 1 米内，眼镜即可自动呈现事实字幕！
