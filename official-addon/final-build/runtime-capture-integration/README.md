## Selector and typed bind

The new assembly selector compares only handle -2. All other handles tail-jump to task71's unchanged production transparent bridge; it does not activate RTLD_NEXT/SELF/ordinary/unknown handles or pass them through an additional C wrapper. The DEFAULT path copies at most19 bytes, one bounded current-task read per expected literal byte including NUL, to check the literal isar_open_instance without directly dereferencing an arbitrary name. It restores incoming errno before calling the real imported dlsym exactly once and preserves that result's errno. No dlerror is consumed by implementation.

Qualification also requires the real result equal the exact self-engine slide+derived exportVA. No target lookup is manufactured in the constructor. On first qualified result only, hidden task93 bind stores the typed original; a duplicate lookup cannot rebind. Only after binding succeeds may the selector return the typed forwarder. Missing/default-other results return unchanged. The hidden bind is not a schema or root grant.

The Runner then calls the real returned function with all11 arguments. The self original checks ID/name/path/bool/max/cache arguments and NaN payloadbits0x7fc00042, incoming errnoE2BIG, writes a known out-pointer, frees the source schema object/payload and returns0x5a. Calls with a real nonnull key and later NULL key both forward exactly once, preserve out/status and remain CaptureWaiting. Because no activation is called, no schema copy or file operation occurs. The snapshot compiles production Capture.c without TIO_CAPTURE_TESTING, so a fixture factory cannot silently enable observation.
