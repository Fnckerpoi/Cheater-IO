# 高德眼镜字幕 R3：中性等待与同会话续显

## 来自真机反馈的问题

用户截图确认：首段实时导航等待时按钮不可用；收到真实指引后才可开启；之后出现“导航指引异常／模式变化，停止旧指引”，通知遮挡后也需手动再开。截图本身不是“15秒断流”证据：旧代码把弱定位、重算、过期、非法帧等统统当成终止，并且导航字幕在手机任何短暂失焦时都停止。R3修正这两条实际路径，并显式展示首次等待，不假装提前获得真实定位。

## 新行为与边界

| 场景 | R3行为 |
| --- | --- |
| 仅规划完成，未点开始 | 不开启字幕，提示先开始导航 |
| 实时导航已开始，首条有效指引未到 | 可以手动确认开启；手机/镜片显示“等待定位与首条导航指引”，不发送旧转向或旧距离 |
| 定位弱、偏航重算、非法转向帧 | 改为对应中性状态，保留当前SID；有效数据恢复后继续同会话 |
| 真实指引超过15秒未更新 | 替换为中性“导航指引暂未更新”，不继续刷新旧距离，不伪造新GPS/时间 |
| 手机普通系统通知造成短暂inactive | 暂停发送，不发关闭；恢复active后有界重绘同SID，不新建preview、不重置保护计时 |
| 眼镜普通通知覆盖，原字幕SID仍ready | 同SID文字有界重绘（最低3.2秒，未变化内容最多约10秒重绘一次）；通知发送事件只是续显提示，不假定收到了镜片退出回执 |
| 设备关闭字幕、外来SID、录音消息、连接失败 | 保留停止保护，不能自动抢占或重开；须人工确认空闲后再开始 |
| 锁屏/真正进入后台、关闭研究页、结束导航/到达 | 仍请求退出字幕；手机实时导航按原定位授权逻辑运行 |
| 4分钟/80帧 | 原始会话限制保留，暂停/重绘不续期 |

**R3不让SDK更快拿到定位，也不能保证固件通知页面消失后一定返回字幕页。** 能自动续显的前提是原字幕会话仍有效；如果通知实际关闭会话，仍安全停止。必须用你的真实iPhone和官方眼镜复测。停止请求不等于镜片确认退出，风险状态以实际道路和手机为准，不作为安全行车设备，不边驾驶、骑车或过马路边操作。

## 真机反馈步骤

1. 进入高德导航，选择实时模式，规划并点击开始。
2. 眼镜显示区应出现 `nav-subtitle-v3`；等待首条数据时显示明确等待文字，可确认开启中性字幕。若仍灰，区域直接给出阻断原因。
3. 收到有效定位和转向后，原字幕会话应变为真实转向/距离，不必重复开启。
4. 在安全静止场景观察一条普通通知：如果只是临时覆盖且原SID有效，应同会话续显；关闭/占用则显示停因，不无限自动重开。
5. 自然遇到弱定位/数据过期时，应该显示中性文字而不是旧箭头/旧距离；再次收到有效指引后续显。
6. 验证停止眼镜不停止手机路线；锁屏/真正后台仍退出字幕，到达、退出页面及4分钟保护都不自动重开。

更多 → 详细诊断标题为“导航状态 · v5 中性续显”。门禁诊断包括 started/routeReady/gpsWeak/rerouting、framePhase、原始与有效回调时间/数量、GPS强度、阻断原因，不记录坐标/私人地名/Key。若等待时间依旧很长，请提供这段门禁信息（遮挡私人路线），用来区分SDK无回调、弱GPS、无效帧和配置连接问题。不要上传完整沙盒或Key。
