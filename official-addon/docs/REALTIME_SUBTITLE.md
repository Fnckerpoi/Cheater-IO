## 实时模式如何开启

1. 确认眼镜已连接并回首页，退出问答、录音、智记、提词、官方实时字幕及其他显示任务。
2. 进入 **TurboIO → 资料 → 高德导航**，选择 **实时导航**，规划自己的附近路线并开始手机导航。首次验收推荐安全、开阔处的短距离步行；勿边驾车、骑车或过马路边操作。
3. 等手机出现转向与持续更新的距离，定位有效后，点击 **开启眼镜字幕显示**。仅规划未开始、数据过期、定位弱或其他显示占用时，按钮仍不可用。
4. 阅读实时指引研究风险，确认眼镜空闲，再点 **已确认，开启字幕导航**。不需要同时启动官方实时字幕收音。
5. 保持手机App和导航页面前台，等待同SID设置ACK。镜片应显示标题 **高德实时导航**，而非“高德模拟导航”；距离是最近一次提交值，不是零延迟指引。
6. 观察变化后先点 **停止眼镜显示（保留手机导航）**，确认手机仍导航、镜片退出；最后点 **结束导航**。退出效果待确认时用眼镜实体按钮退出，不连续重开。

## 没有取消的保护

| 条件 | 当前行为 |
| --- | --- |
| 新会话 | 必须用户确认空闲并生成新SID；等对应ACK后才发文字，不抢占已有任务 |
| 正常更新 | 最短3.2秒，只保留最新帧，不重复发送未变化文字；同一时刻仅一笔在途提交 |
| 手机失去前台／锁屏 | 请求退出眼镜字幕；手机实时路线按原后台定位条件运行，不自动重新开启字幕 |
| 定位信号弱 | 停止眼镜旧指引；定位恢复、新鲜指引出现后也须用户确认并手动重新开启 |
| 偏航重算 | 立即停止旧指引；新路线就绪后不自动重开字幕 |
| 断流超过15秒 | 停止旧指引；不再持续发送缓存文字 |
| 到达、错误、结束／退出页面 | 请求退出本次字幕会话，不处理另一个SID |
| 模拟／实时模式变化 | 已开启字幕的高德会话停止，不能混用两种模式的旧帧 |
| 字幕音频消息／外来会话／连接变化 | 沿用现有协议保护停止，不主动发录音启动命令 |
| 4分钟／80帧 | 保留研究保护上限；不是无限时、后台或经过安全认证的导航产品 |

停止请求和“已提交帧数”不等于镜片渲染／退出已确认。镜片可能停留旧内容，发生异常以实际路况与手机指引为准；不要循环重开规避保护，不作为行车决策设备。
