# R4 高德路线持续字幕、受控后台推送与自动开启（已获用户五项真机反馈）

**R4基线已由用户确认，新版二次开始修复/自动地图/独立底栏实时入口见 [R5说明](NAVIGATION_R5.md)。下面保留R4历史操作与风险，不代表R5已经真机通过。**

## 范围

沿用普通V2研究副本、自己的高德iOS Key和官方眼镜固件。保留深色底栏与HTTP任意IP模型；不刷固件，不包含MapKit实验HUD。这是实验性辅助指引，不作为行车安全设备。

用户批准的三项要求同时实现：
1. 真实高德导航字幕随当前路线持续，不再因4分钟/80帧结束；不循环重建SID续期。
2. 已在前台开始的真实路线，在系统授予后台定位执行机会时尝试原生文字推送，退桌面/切App/锁屏不主动关闭合规路线。
3. 开始导航成功后自动开启眼镜字幕，开始操作内确认眼镜空闲，不需要再点一次“开启眼镜字幕显示”。

模拟、手动字幕诊断以及MapKit原调用仍保留前台及240秒/80帧短时策略，不能用模拟结果代替后台真实GPS导航。

## 开始与结束的行为

- 规划不自动定位或显示。点击“开始导航”会出现“开始导航并自动显示到眼镜”：确认录音、智记、问答、提词、官方字幕等任务已结束。
- 点“已确认，开始并自动显示”后才调用SDK。SDK拒绝开始/定位未授权/已离开前台时不自动开镜片。
- 真实路线开始成功后，路线服务获得唯一内存token，自动请求字幕预览；等新SID设置ACK后才发等待文字/真实指引。模拟在首条有效SDK回调后尝试自动显示。
- 连接/配置未就绪、字幕phase非idle、其他显示占用时，不强迫退出其他任务、不重复尝试；手机导航继续，页面明确提示原因，可人工检查。
- 真正导航期间，返回App首页、离开导航页或关闭研究页面**不代表结束真实导航**。服务持有当前引擎拥有者；再进入导航入口返回同一条路线。结束需要点“结束导航”；到达/错误/权限撤销仍收尾。
- “停止眼镜显示”保留手机定位路线，且本次自动开启不会把用户刚关闭的字幕再打开。需要时前台手动确认开启。
- 强退或系统终止进程后不恢复或重新启动；只保存脱敏诊断，不保存路线/位置轨迹或可恢复执行会话。

## 后台与保护

| 条件 | R4处理 |
| --- | --- |
| 前台新会话 | 必须本次开始确认/SDK成功/配置连接/空闲，保持新SID ACK门槛 |
| 真实路线后台 | 活跃token、定位授权、已启用合法后台location条件共同满足才放行type5文本；后台不能发新type7预览或开始新路线 |
| 更新驱动 | 实际高德转向/GPS定位回调、原生发送完成、同SID ACK驱动；前台守卫用于收尾，不能把NSTimer当无限后台权限 |
| 定位弱/偏航重算/无效/15秒过期 | 中性文字，不发送旧转向/距离、不伪造新定位时间；有效数据后同会话恢复 |
| 发送 | 最短3.2秒，最新帧合并、单笔在途、约10秒有界同内容重绘；后台SDK拒绝/8秒无完成安全停止字幕 |
| 其他SID/设备变化/字幕音频 | 停止，不抢占，不自动新建会话 |
| 权限撤销/后台条件失效 | 禁止后台发送，按路线策略停止；不申请“始终”权限、不静音播放/假定位保活 |
| 真实路线240秒/80帧 | 不再作为结束条件，使用明确routeScoped API；默认实验调用仍受限 |
| 结束/到达/错误 | 撤销内存token、停止本扩展引擎/定位、请求退出本SID，不停止其他业务引擎 |

源App的location、bluetooth-central和配件模式原样保留。缺少location时前台可以导航，后台会停止；本版不会静默添加权限或修改官方蓝牙插件。传输使用原生插件handleMethodCall，不依赖Flutter页面定时器；但真实iOS后台时原生插件是否持续回调仍需要你的设备验证。系统可能暂停/终止应用，弱定位、低电量或蓝牙断连也会中断，不承诺永远在线。
