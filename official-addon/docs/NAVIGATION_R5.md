## 本次修改

1. **第二次开始不再需要杀进程。** 旧代码在检查“必须idle”后才处理当前空闲确认；第一条路线停止后软件可能为stopping/uncertain，因而把用户新确认拦截。本次仅允许前台新开始操作、明确确认镜片已回首页、旧状态确为本扩展routeScoped已停止路线时重置确认并新建SID；运行中的starting/ready、非本路线、未确认或后台不重置。
2. **进页自动加载地图。** 已保存自己的iOS Key且已同意高德SDK隐私说明时自动openMap；没有Key提示设置，未同意时仍由本人决定，不自动同意。拒绝后不循环弹窗。自动看地图不会自动开始GPS/路线/字幕。
3. **首页覆盖底栏六项。** 保留原RayNeo／眼镜／记忆(回忆)／发现(探索)四项的实时无障碍点击转交，TurboIO后新增“导航”图标；固定深色样式保留。覆盖宽度调整以确保300pt以上机型六个触摸区均至少44pt。原官方四项缺失、布局不支持、VoiceOver或弹层时仍安全回退。
4. **导航是独立原生页面。** 第六图标直接打开出行页，不必进入资料列表；“返回首页”关闭页面但不结束活跃路线。再次进入复用原路线/容器；结束请主动点“结束导航”。TurboIO原研究入口不变，导航旧入口暂保留以兼容既有操作。
5. **正常页面只提供实时出行。** 步行／骑行／驾车；模拟验收、北京演示、选模拟起点与备用实验菜单不再露出。底层显式离线测试夹具保留，不当作生产运行模式。自动显示、后台、弱GPS/重算/过期中性提示与权限/占用/音频/外来SID/停止保护不削弱。

将当前功能作为日常实时入口不等于认证安全导航产品。不要边驾驶、骑车或过马路边操作，以道路和成熟手机导航产品为准。

## 使用高德官方App的另一条方案

当前项目实际上是**传统AMapNaviKit 11.3.100 + Foundation1.9.4 + Search9.8.1**，不应称为已接入“轻量出行专用SDK”。自己的SDK会话和高德官方App会话不是一回事。

官方普通 `iosamap://navi` / `path` 能唤起高德；本次未发现其连续转向/距离回调的公开证据。另一方面，官网AIoT文档链接的iOS Link合作SDK明确描述AMapLinkManager/授权IPC、来源AMap=2的UpdateNaviInfo及结构化回传；这是可咨询的正式路径，但需专用SDK产物和授权，官网要求联系高德获取，不等同裸URI或当前包已经支持。

近期推荐保留已实测的“本应用SDK → 眼镜”作为主线；若必须来自官方App同一条路线，向高德/厂商申请Link/Agent合作能力与包，确认个人接入资格、步行/骑行/驾车字段、后台与锁屏规则、数据转发许可后再开发。截图OCR/屏幕广播只适合显式同意的有限静止实验，不能当可靠产品接口；iOS普通App没有全局读取其他App通知的通用权限。

完整一手来源与接入问题清单：[高德官方App方案研究](AMAP_APP_NAVIGATION_OPTIONS.md)。本次没有安装合作SDK或登录授权，公开文档证据不代表已获得接入资格或回传实测。
