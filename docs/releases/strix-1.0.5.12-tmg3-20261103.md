## 固件与源码

TMG3 迁移包含菜单及应用运行时、显示与导航运行时、看板、相机和文本载体等既有增强模块，并适配 127 原厂的生命周期、Head Manager/Slot、Launcher 发布地址及 Renderer 接口。相对官方原包，仅 AP 载荷与清单中的 AP 大小和 MD5 改变，其他 14 个载荷保持逐字节一致。

完整源码、链接脚本与固定构建输入位于 `firmware-research/strix-1.0.5.12-tmg3/`。使用该目录 README 中的命令和 OHOS 15 原生 LLVM 可重建相同 ZIP；原厂 ZIP 从本 Release 获取。全量重建覆盖 78 个对象，包审计检查 34 个补丁位点、7 处启动描述符及伴生载荷。

Android 源码支持雷鸟 App 1.0.10（258）的宿主映射、官方 OTA 查询与目录验证、独立原厂/TMG3 身份及结果保护，并整合主动回报与组合 HUD。普通业务临时许可的新增代码仅完成离线验证，未部署到此次验收手机。

## 验证

- 两份 ZIP 均通过 CRC、16 成员集合及 15 载荷清单大小/MD5 校验。TMG3 全量重建 ZIP、AP 和模块与已审查产物身份一致。
- Android 1.0.10 真实固件查询与实际解压目录通过；原厂对照更新成功，TMG3 修复版完成 239 片/AP 7515400 字节校验和更新。用户确认刷入及完成回首页/解除结果保护后通信恢复，手机回读无待核对记录、授权 0、LOCKED。
- 业务许可源码通过策略回归与真实 Bridge 产品源码的 JVM 宿主集成验证；Android、SDK、Service 和 preferences 使用边界替身。

## 使用与验证范围

该 TMG3 是基于官方固件的社区修改版。当前现场证据对应 RayNeo iO、1.0.5.12 与 Android 1.0.10 组合，不代表其他型号或版本的兼容性。眼镜自然回到首页并确认基本功能后，应按受控升级页完成结果确认；传输完成与版本号相同本身不能替代安装和功能验收。

本 Release 提供两份固件和源码，不包含新编译的 Android APK。各增强模块的镜片功能仍需按实际使用逐项验收。官方原包保持原始字节，仅调整下载文件名。

发布前验证完成 109 个产品 Java 与 57 个根测试源码编译、18 套 DSH 测试、7 套主动回报集成、2440 项 OTA 策略/包断言、55 项 Bridge 宿主断言及 5 个 Node 测试脚本。装配与宿主映射等 Python 测试通过；部分历史 APK/原生库依赖用例因本地夹具缺失未完成，部分可选用例跳过，未声明历史全套测试通过。
