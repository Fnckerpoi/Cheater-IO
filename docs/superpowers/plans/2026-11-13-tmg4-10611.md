# TMG4-10611 Implementation Plan

> **For agentic workers:** Use superpower-subagent-driven-development to implement each task with scoped ownership and integrated review.

**Goal:** 从 1.0.6.11 基座构建 TMG4-10611，移除 Android/AP 四项自定义业务并保留共享能力。

**Architecture:** 延用已完成的 Android 1.0.20 与新版 AP ABI 迁移。Android 提取字幕、整数/CRC、UTF-8 共享职责并从新构建删除导航、番茄、阅读、音乐业务；AP 新建独立 TMG4 构建目录，复用已核实 ABI 与原厂输入，保留历史源码。最后将实际产物登记到 OTA 候选档案。

**Tech Stack:** Java/Android DEX、Python/Node 构建器、C/Thumb AP 模块、OHOS LLVM。

**Spec:** docs/design/TMG4-10611-requirements.md

## Global Constraints

- 基座 1.0.6.11；构建身份 TMG4-10611；Android 1.0.20；iOS 不变。
- 保留原厂导航、其他现有功能、历史源码、旧用户数据。
- 保留原 OTA 通道、准备模式与独立授权、历史结果保护；未证实查询版本不猜值。
- 非 AP 原厂载荷与烧录元数据逐字节保留；包身份来自实际构建。
- 当前 android 分支含先前迁移成果；原地工作，按文件车道协作，不重置、不提交既有改动、不接设备。

## Review Focus

- 字幕/SCADA 对显示租约与输入共享能力依赖，重构后行为保留。
- 新构建 DEX 不包含四项业务，不能仅隐藏入口。
- 固件菜单数量、点击、退出与原厂导航正确映射。
- 历史待确认 OTA 记录不能采纳新包身份或自动解除保护。
- 未确定的官方查询/回读值不能从自定义代号推导。
